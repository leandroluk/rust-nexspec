NexSpec
The problem

Agents read files.
Projects are made of relationships.

  • Whole files get dumped into the prompt — tokens burn on code the task never needed.
  • Specs and code live apart — which function satisfies REQ-105?
  • Impact is guesswork — what breaks if I change this symbol?
  • External indexers mean daemons, interpreters and setup.

NexSpec
Design choices

Built to never serve a half-written index.

  • Crash-safe. Every write goes through one coordinator: WAL first, atomic rename after. --resume recovers deterministically.
  • Lock-free reads. Immutable mmap base + copy-on-write delta. Readers never block on a sync.
  • Lean when you need it. The vector engine is optional and lazy. CI builds skip it entirely.
  • Incremental. Only what changed in Git gets reprocessed.
